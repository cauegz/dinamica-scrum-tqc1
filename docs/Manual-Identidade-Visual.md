#  Manual de identidade visual - TQC 1

## Sobre:
    Esta documentação explicitará os elementos visuais presentes na landing page e quais padrões devem ser seguidos pelo grupo.
    o protótipo da aplicação foi desenvolvido no Canva e pode ser acessado pelo seguinte link:
    https://canva.link/2abenkkb6e54f0a

    Icones -> https://fontawesome.com/
## Cores:
    preferencialmente usar variáveis css
    #FAA926 -> fontes maiores e estruturas do corpo
    #012E73 -> corpo da página
    #1089E3 -> detalhes
    #f7f8fa -> fontes

## Fontes:
    Cabeçalho, Paragrafos e Subtitulos de sessões: Fira Code
    Titulos de sessões: Lovelo

## Sobre Sessões:
    ### Cabeçalho: 
        deve conter a logo da residência, alinhado horintalmente, para dispositivos menores, adptar o cabeçalho para ser visto verticalmente

    ### Identidade: 
        Titulo:    TQC1 MANHÃ                        T             T
                    slogan                           |  foto turma |
                [conhecer integrantes]               L             T
    ### Quem somos: 
        seguir padrão de formatação e possivelmente no futuro implementar os valores da turma em cards ao lado

    ### Integrantes: 
        Integrantes separados por cards, cada card deve conter [avatar, especialização e idade] ele também deve ter links para o redirecionamentos para as páginas do github e/ou portfolios dos participantes, os cards devem estar centralizados em 
        formato de fichas, seguir o padrão de grade(como os de aplicativos de produtos de supermercado) podendo clicar em ver mais com uma setinha apontando para baixo. Caso a foto do integrante não seja informada, utilizar o icone de perfil do font awsome

    ### Mural: 
        expor as frases dos participantes entre parentes na cor #FAA926 com o nome abaixo

    ### Linha do Tempo:
        deve ser posta horizontalmente e conter icones indicando cada etapa que já passou da trajetório, no hover mostrar a descrição da terefa
